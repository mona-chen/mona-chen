### Inkwell

**Inkwell is my answer to a simple question:**

> **What if WordPress were rebuilt from scratch today?**

Not redesigned.

Rebuilt.

Inkwell is a modern CMS and publishing platform built around a Rails-native architecture:

```text
Ruby on Rails
Hotwire
Turbo
Stimulus
Tailwind CSS
ViewComponent
```

The architecture rethinks several assumptions inherited from traditional CMS platforms.

Instead of shortcode-heavy content, Inkwell uses **structured blocks**.

Instead of loosely defined extension points, it uses a **typed hook system**.

Instead of bolting plugins onto the side, plugins are designed as **Rails Engines**.

Instead of treating themes as giant bundles of logic, themes are built around **view paths and presentation primitives**.

The goal is not to create "WordPress in Rails."

The goal is to rethink what a flexible, extensible publishing system should look like with modern application architecture.

Some of the areas I'm actively exploring include:

* Block-based content architecture
* Plugin systems
* Theme architecture
* Runtime extensibility
* Modern admin UX
* Publishing workflows
* Developer-friendly hooks and APIs
* CMS performance
* Hotwire-first interfaces
* Rails as an application platform

Inkwell sits at the intersection of **product design, framework architecture, extensibility, and publishing infrastructure**.
